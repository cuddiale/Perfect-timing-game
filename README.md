# Blind Timer Game ⏱️

Un mini-gioco web "mobile-first" basato sul tempismo, sul ritmo e sul proprio orologio biologico. Il progetto è sviluppato puramente client-side ed è ottimizzato per dispositivi mobile.

## 🎮 Come si gioca

1. Il gioco genera un tempo target casuale (es. `12.58` secondi).
2. Premi il bottone per avviare il timer.
3. Il timer sarà visibile solo per i primi 2-3 secondi per darti il ritmo, poi **scomparirà**.
4. Conta a mente! Premi nuovamente il bottone quando pensi che il tempo sia scaduto esattamente al secondo target.
5. **I Livelli:** Più si va avanti, più la finestra di tolleranza (lo scarto di errore ammesso) si rimpicciolisce, aumentando la difficoltà.

## 🛠️ Tech Stack

- **HTML5** (Struttura semantica e interfaccia)
- **CSS3** (Design responsive Mobile-First e animazioni)
- **JavaScript (Vanilla)** (Logica di gioco, gestione dei livelli e del timer)
- **Web Storage API (LocalStorage)** (Per il salvataggio del record personale senza backend)
